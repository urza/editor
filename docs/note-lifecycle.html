Where a note goes in vrtti

On each device, a note is in one of four states: Open, Recent, a space drawer, or Trash. This page shows what moves a note from one state to another on one device. It also shows what a change on one device does on the other devices.

Words on this page

Local note
A note with sync off. It is only on this device. A file that you opened from disk is a local file.
Synced note
A note in a space. The server keeps it, and each device of the space gets it.
Space
A group of devices that share notes. Each device sets one mode per space. In an “Open as tabs” space, new notes open as tabs. In a “Titles only” space, the device keeps only the titles until you open a note.
Title row
A row in a space drawer that has only the title of a note. The text stays on the server until you click the row.
Deleted mark
The record that a device sends to the server when it deletes a synced note (a tombstone, in the code). A “detached” mark tells the other devices that a note stopped syncing.

Recent, each space drawer, and Trash have icons in the bottom bar of the sidebar. Recent is a clock, each space is a colored badge with its initials (for example “P” for personal, “DW” for dev-work), and Trash is a trash can. When one of them is empty, its icon is not there. On desktop, a click opens its list in a drawer above the bar. On the phone, a tap opens the list on the full screen.

The diagram leaves out edits from other devices. An edit changes the copy where it is, and the copy does not move. The tables below give each case.

Close never deletes a note that has text. A closed local note goes to Recent, and a closed synced note goes to its space drawer. To delete a note on purpose, use “Move to trash”. Trash keeps the note for 30 days, so you can undo a wrong click. An empty note is the one exception. When you close it, vrtti removes it, because it holds nothing to lose.

Ways to delete

Desktop
  • The row menu (⋯) has “Move to trash”. For a file, it has “Remove from list”.
  • A row in Recent or in a space drawer shows a trash icon on hover.
  • Delete mode. Click the trash-can button at the top of the sidebar. The sidebar gets a red edge and a “delete mode · Esc” label. Each Open row shows a red trash icon in place of ×.
  • In Delete mode, click the trash icon, or press Ctrl+W or Alt+W, to move a note to Trash. The mode stops on Esc, a second click of the button, a click of the label, an edit in the note, or a reload.
  • Shift+click ×. Hold Shift, and the × turns red. The click then moves the note to Trash.
Phone
  • Swipe left on an Open row only closes the note. It never deletes.
  • The row menu (⋯) has “Move to trash”.
  • The bottom bar shows Recent, a badge for each space, and Trash, each with a count. A tap opens that list on the full screen. “← Open” and the Android Back button go back to Open.
  • A tap on a Trash row opens its menu, with restore and delete.
  • A title row has the tag “server”. A tap gets the text.
  • The phone has no Delete mode, no View filter, and no Space Windows.

A note with a PIN lock asks for the PIN before “Move to trash” or “Delete permanently”.

Space Windows (desktop)

  • A space drawer has a button “Open <space> in new window”. Each space can have one window. A second click brings that window forward.
  • The new window opens each note of the space as a tab. It takes the open tabs of that space from the other windows and the closed notes from the space drawer.
  • For each title row, the window gets the text from the server in the background and opens it as a tab. Offline, a title row that it cannot get stays in the drawer.
  • This happens only when the window opens for the first time. After a reload, the window keeps the tabs that you left open.
  • In a Space Window, + and Ctrl+N make notes in that space. The window title is “<note> (<space>) - vrtti”.
  • A new note from another device opens as a tab in the Space Window of its space. This is true also for a “Titles only” space.
  • When you close the Space Window, its notes go back to the space drawer. Notes of a “Titles only” space go back to title rows.
  • If this device loses the space, the Space Window closes, and its notes go to Trash.

Why it works this way

A delete from another device cannot wipe your copy

A deleted mark from the server never removes a note at once. Each device that holds the text moves its own copy to Trash and keeps it for 30 days. So a server in the wrong hands, or a mistake on another device, cannot wipe a note with no way back.

No dialog before a delete

Trash is the safety net, so “Move to trash” does not ask. A wrong click costs one restore. Only “Delete permanently” has no undo, and it works only inside Trash.

Recent does not grow for ever

A local note that you do not open for 30 days goes to Trash, and after 30 more days it is gone. Synced notes in a space drawer never expire, because the server keeps them.

“Titles only” stays light

A device in a “Titles only” space keeps only the notes that you open. When you close a note, the device drops its text again and keeps the title row.
